# Ads Recovery interface

Native macOS utility, Operate mode. Visual reference: PAD team site and tools section.

- Background #f5f5f5; ink #1a1a1a; supporting text #626262; blue #2f54eb.
- macOS system font, regular-weight headings, restrained fixed type sizes.
- A single window with a three-step introduction and a working dashboard. Header and agency footer remain stable.
- Explain broad Accessibility permission before requesting it. Skipping permission keeps the app usable for exploration.
- Keep automatic recovery explicitly experimental and off on launch. A visible table is not proof that all advertising data loaded.
- Original PAD mascot in a quiet footer with a user-triggered pad.team link. No website content is loaded into the app.
- Original blue recovery/chart icon and a monochrome template variant for the menu bar.
